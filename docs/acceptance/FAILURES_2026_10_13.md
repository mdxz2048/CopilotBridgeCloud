# 2026-10-13 失败反馈分析（脱敏）

北京时间 15:27:23–15:29:02，Bridge 0.3.13、deepseek/deepseek-flash，四条均为 cloud_http / 422 UNSUPPORTED_PROTOCOL。管理员保留的失败反馈当前共四条。

## 已确认原因

apps/api/src/native-responses.ts 的 DeepSeek supportedItems 白名单不含 tool_search_call / tool_search_output。validateNativeRequest 在 gateway 路由校验阶段拒绝该历史，返回“不支持此历史条目，请提供完整未压缩历史。”。校验在上游执行及计费记录创建之前。

在当前生产容器导入同一校验函数，分别用两种合成条目做最小复现，均返回 422 UNSUPPORTED_PROTOCOL。生产日志按四个 requestId 关联，全部返回 422。因此这四条是 Bridge 的 DeepSeek 历史兼容缺口，不能归因为余额、网络、请求大小或供应商 429。

反复“继续”会再次携带同样的历史条目，重复触发。全新且不含这些条目的会话可绕开此检查，但再次触发工具发现仍可能出现。新会话真实任务尚未重跑，不能保证长期不再发生。
