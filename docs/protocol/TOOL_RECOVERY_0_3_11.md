# 0.3.11 协作历史兼容

DeepSeek 原生 Responses 不接受官方运行时的 agent_message。App 和 API 将其转换为明确标识的外部 user/input_text 消息信封，JSON 保留原始作者、接收者、消息 ID、正文和附加字段。其他未知类型继续按现有能力校验，不能简单全部放行。OpenAI 路径不转换该条目，本版不声称它已经完成实际验收。

本地工具恢复、部分结果等待、名称绑定及会话隔离由 App 管理；Cloud 不执行工具或伪造成功结果。API 不修改认证、计费、账户、设备或套餐规则。

回归覆盖信封字段无损、DeepSeek 接受转换、实际 HTTP 请求中的输入形状以及 OpenAI 既有透传行为。
