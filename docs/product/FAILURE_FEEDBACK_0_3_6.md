# 调用失败自动反馈

日期：2026-10-12，Asia/Shanghai。版本：Bridge 0.3.6。已正式发布，功能与真实反馈验收通过；保留宿主能力边界。

## 用户行为

Bridge Cloud 调用失败时自动记录该次请求、转发请求、回复或流事件片段，以及错误阶段和请求编号。反馈在后台发送，不阻塞聊天、不重发模型请求、不执行工具，也不产生模型调用费用。正常会话不会上传诊断正文。用户主动取消不作为模型故障反馈。

记录用于管理员定位客户端兼容、网络、模型和工具回传问题。请求及回复中的文本可能包含用户输入、工具参数和文档提取结果；仅保留限量故障片段。登录凭证、API Key、Cookie、附件二进制、文件 Base64 和加密上下文会移除。诊断脱敏与正文截断独立于模型转发，不改变实际模型请求。

## 关联与查看

服务端根据已验证的平台账号和设备补齐用户 ID、邮箱、设备、客户端版本及接收时间，不接受客户端自报邮箱作为身份。反馈的账户归属必须与当前登录账号一致，账号切换不能将旧反馈归给新用户。

管理员通过“失败反馈”查看和按邮箱、错误码检索故障，详情展示请求、转发请求、回复片段和请求关联编号。普通用户无权读取其他用户诊断。删除操作保留审计摘要，不将正文写入普通服务日志。

## 容量与可靠性

客户端报告目标不超过 96 KiB；服务端接口硬上限 128 KiB。客户端优先保留最近的会话输入和终止错误，标明截断。断网反馈暂存于账号绑定的加密队列：最多 20 条、2 MiB、7 天；无法使用系统加密时只放内存。只重试反馈上传，使用相同报告 ID 避免重复记录。

服务端正文 AES 加密保存，接收时间起保留 14 天；全局最多 1,000 条、加密载荷合计 128 MiB，超限按接收时间清理旧记录。上传时清理并每小时后台清理，读取接口隐藏过期记录。每个用户每小时最多接收 30 条新反馈：实现为从该用户计数窗口开始时刻起的一小时窗口，不是精确滚动窗口。幂等重传不消耗该额度；删除或容量清理不能重置持久计数。此限制与用户模型消费额度独立。

## 协议

`POST /api/v1/diagnostics/failures` 使用现有设备凭证和请求签名。主要字段：`id`、`ownerUserId`、`occurredAt`、`appVersion`、`traceId`、请求/回复/会话编号、`stage`、`error`、`request.desktop`、`request.forwarded`、`reply.http`、`reply.events`、`truncated`。

阶段为 `local_validation`、`cloud_http`、`cloud_transport`、`stream_failed`、`stream_incomplete` 或 `stream_disconnected`。返回 `{id, received: true, duplicate}`。

管理员使用 `GET /api/v1/admin/diagnostics/failures` 分页查询，`GET /api/v1/admin/diagnostics/failures/:id` 查看详情，`DELETE /api/v1/admin/diagnostics/failures/:id` 删除。最终结构由协议定义和自动化测试维护。

总计四条路由，其中管理员路由三条。上传必须为设备账号（不能用网站会话替代），具有现有 DPoP 签名和匹配的 `X-Device-ID`。报告 ID 为 UUID；客户端归属不匹配拒绝，同 ID 不同用户拒绝。服务端覆盖客户端版本为已验证设备版本，并采用账号邮箱。详情返回 `{report: {...metadata, payload}}`；列表支持精确邮箱、错误码和 `page`，每页 25 条。删除校验管理员及同源 Origin，返回 `{id, deleted: true}`，保留不含正文的 `DIAGNOSTIC_DELETED` 审计。

正文为有界、脱敏的诊断片段，不承诺完整抓包或恢复任意原始请求。客户端会截取输入、工具输出和最近 32 个流事件；服务端再次限制深度、条目和文本长度，截断标记随报告保存。敏感内容仍可能出现在普通自然语言里，管理员入口因此仅限管理员，不能把脱敏理解为任意故障文本都不含个人信息。

## 长代码、长工具运行的边界

失败诊断的 96 KiB 限额不作用于模型转发正文。现有完整上下文路径可以携带长代码和工具输出；新回归以 100 KB 工具输出、模拟超过一小时的暂停核对转发字节，不等同于真实官方宿主长命令验收。Cloud 的 600 秒是单次模型生成请求总时限，不是工具运行时限。工具由官方宿主执行，Bridge 不新增执行器或循环。完整上下文续接不依赖一小时 Cloud 历史缓存，但未知引用、缺失历史、宿主策略和真实供应商能力仍有各自限制，不能承诺任意长度或所有命令必成功。
