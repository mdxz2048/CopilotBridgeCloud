# 官网产品与使用指南（2026-10-13）

UI 设计角色先制定结构和文案，再实现并审阅桌面与手机截图。

首页顺序：原生 ChatGPT 体验 / 模型由你选择 → 原生客户端、网络无需自行配置代理、模型选择三个优势 → 三步上手 → 模型说明 → 常见问题 → 下载入口。

实际流程：下载并安装 Bridge，用分配账号登录；通过 Bridge 引导安装官方 ChatGPT，已安装可跳过；选择可用模型并开启 Cloud，按提示重新打开 ChatGPT。使用时保持 Bridge 运行，更换模型后新开会话。关闭 Cloud 后按提示重新打开 ChatGPT，回到原账号。

删除旧 GitHub Copilot、本地模式、独立环境、注销/重新登录 Windows 等过时说明。Luna 保留待开通说明，不宣传为已经可用。首页为原创流程示意，非官方客户端截图。

下载页优先展示最新 Bridge 安装包，统一 QuickStart 三步组件，官方 ChatGPT 备用包与 SHA256 使用可展开区域，保留真实 API 地址、版本、加载与失败重试。套餐页改为管理员管理账号/余额/模型权限/设备说明，不再声称套餐按周期额度与访问频率限制。导航访客主入口改为下载。

样式使用 CSS module 隔离；系统字体替代外部 Google Fonts，页面不需要请求 Google 字体服务。

验证：Next.js 生产构建与 TypeScript 成功；Web 15 项通过。真实构建页面在 375、768、1440 宽度：首页、下载页、套餐页共 9 个布局无横向溢出，步骤导航、FAQ、备用安装与 SHA 展开验证；API 为合成 fixture，不是实际付款或安装验收。UI 角色审阅通过。上线后另核对公网页面和真实发布接口。

App 仍为 0.3.13，本次仅 Web 更新，无 API / 数据库 / 客户端变更。
