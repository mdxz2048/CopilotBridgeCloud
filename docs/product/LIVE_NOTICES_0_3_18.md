# 0.3.18 实时通知与连接诊断

后台“活动与通知”支持每条通知的标题（80字）、正文（6000字）、显示/隐藏、增加与删除，最多10条。修改后统一保存，沿用管理员鉴权、同源校验、revision并发保护及审计。隐藏草稿的正文不会进入公开配置。历史单文本通知读取时转换，保留显示状态，无数据库迁移。

App运行时随5秒配置轮询自动同步，无需退出、重新登录或切换Cloud；离线时保留最后成功配置，恢复联网后继续同步。发布信息仍按5分钟缓存，配置请求合并，服务端响应no-store。后台提示的5秒是正常联网时的下一次轮询，网络延迟/离线不作即时送达承诺。

底栏只显示标题，长标题省略；单条静态，多条10秒轮播，附位置及手动下一条。点击打开与账户/设置同风格的紧凑弹窗，正文支持换行并在弹窗内滚动。悬停、焦点、阅读、窗口隐藏或减弱动态时暂停。内容编辑会更新已打开的详情，隐藏/删除会收起对应详情。无通知沿用原底栏，原有错误/维护/安装等抑制规则保持。

campaign.announcementEnabled默认true，可单独隐藏自动邀请活动通知；campaign.enabled仍控制邀请活动资格和邀请文案，不因隐藏广播而停止奖励。

公开announcements保留text（标题）兼容旧客户端，新增可选title/content。旧配置仍能被App读取；用户需升级0.3.18以使用完整正文和快速同步。
