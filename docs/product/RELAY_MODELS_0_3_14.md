# GPT 中转与模型开放（0.3.14）

Cloud 管理上游 URL、加密 API Key 和模型实例。App 只连接 Cloud；切换中转商、导入目录和修改用户权限不需要在 App 保存上游配置。

管理员在 GPT 连接中填写 API 地址和 Key，保存并导入该 Key 的 `/models` 目录。目录不是生成验收：新模型和实例默认停用，需执行真实 Responses 文本、流式和工具检查，再启用实例及逻辑模型，并在用户管理中授权。用户目录只返回当前有权限且有可用连接的模型。官方 OpenAI 地址及原生请求路径仍受支持。

本次中转实际目录为 gpt-5.6-terra、gpt-5.5、gpt-5.6-sol、gpt-6-sol、gpt-6.1-sol。仅开放 GPT-6 Sol 和既有 DeepSeek Flash；其余 GPT 型号停用。gpt-6-luna 在该 Key 分组返回 model_not_found，移除旧的预置条目。旧型号停用并归档，从管理列表移除，数据库历史账单和审计记录保留。

该中转的空工具请求返回 502。连接级兼容选项为无工具请求增加禁用的占位函数并设置 tool_choice=none；不执行工具。已有工具定义保持原样，意外占位工具调用作为协议错误拒绝。官方接口默认不开启该选项。

用户确认 GPT 售价为 USD 2/10/0.1 每百万输入/输出/缓存读取 Token，汇率固定 7，不乘 0.08。对应人民币 14/70/0.7 每百万 Token；费率版本保存为每千 Token 140/700/7 AI_POINT（10000 AI_POINT=1 元）。按实际用量扣余额，推理 Token 包含在输出中，避免重复计费。Responses 没有单列 5 分钟缓存写入用量，因此不额外收缓存写入费。费率先发布，后启用模型，既有 DeepSeek 费率保留。

配置密钥仅服务端加密保存，不写入 App、Git、测试证据或发布说明。导入及归档需要管理员权限并写审计记录。
