# 0.3.9 取消模型请求次数限流

按用户要求，模型POST /v1/responses和客户端已识别的模型/账号/用量GET状态接口不参加IP请求次数限流。模型生成不再检查账号、设备、套餐RPM，后台查询不会因为次数影响任务继续。

连续工具结果保持同账号、设备、会话和完整历史校验，不再有8次计数边界。工具关联状态在每次有效生成后刷新65分钟窗口；这是关联状态保留时间，不是整个任务的总时长上限。长任务可以跨多次模型生成和工具操作继续。

保留：认证与设备证明、模型权限、人民币余额和周期消费上限、每个用户同时运行的模型请求并发上限、上游自身资源限制。登录/注册等公共接口的防刷和诊断上传30次/小时限额保留，不参与正常模型请求次数计数。请求大小、上游连接/空闲超时和供应商模型上下文上限未在本次改变。

API billing的accountRpm/deviceRpm以及模型返回limits的account_rpm/device_rpm/plan_rpm为0，表示模型请求次数不限。原管理端存储的RPM字段不再限制模型调用，不应理解为它们仍在执行。客户端账户页改为显示“模型请求次数不限”。没有增大为一个更高但仍会触发的数字。

本期只有Cloud API和App发布，Web无需重建；新版App为0.3.9，服务器继续仅保留最新安装包并准入最新版。测试与实际发布证据见验收文档。
