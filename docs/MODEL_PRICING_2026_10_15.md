# 模型售价倍率

管理员的“模型售价”页展示配置过凭据的 DeepSeek / OpenAI 上游余额、各上游累计扣用户余额，以及服务端累计扣款。中转未实现余额接口时显示未知，不填零。默认排除 `@example.test` 内部验收账号。

每个模型只编辑倍率（0.01–100）。售价 = 已确认的价格基准 × 倍率；1 表示原价，1.1 表示加价 10%，低于 1 表示补贴。只读 Token 价格弹窗按人民币/百万 Token 展示输入、缓存输入和输出；可预览未保存倍率，明确标记未保存。DeepSeek 保留北京时间工作日峰谷及节假日日历，移除页面上的全局倍率和逐项单价编辑入口。

DeepSeek 基准沿用现有 money_policy；GPT-6 Sol 采用管理员已提供的输入 USD 2、缓存输入 USD 0.1、输出 USD 10 / 百万 Token，汇率 7。该价目是倍率参考，不冒充经过供应商账单核对的实际成本。其他缺少价格基准的模型显示缺失，禁止保存倍率。未显式保存 GPT 倍率前保留原费率。

## 结算与审计

- `GET /api/v1/admin/model-pricing`：管理员读取余额、倍率、基准与聚合统计；不暴露凭据。
- `PUT /api/v1/admin/model-pricing/:id`：同源管理员提交 `{multiplier, expectedRevision}`；过期版本返回 409，非法倍率返回 400。
- `system_settings.model_markup:<model UUID>` 保存独立倍率和修订号，无新数据库迁移。保存操作记录 MODEL_MARKUP_UPDATED 审计事件。
- 保存和请求费率刷新共用每模型数据库事务锁；在事务中读取最新倍率，避免在途刷新覆盖管理员保存。同步发布模型主上游及同模型、同类别实例的费率。
- 新请求捕获费率版本；旧版本只退役，不修改数值，已开始请求和历史账单保持旧价。保留钱包非负、用量幂等、余额不足拒绝等原有结算约束。
- 每次消费沿用向上取整到人民币 0.0001 元的规则。

已知成本优先采用请求审计里的供应商报告值，其次采用估算；未知成本不计作零。估算毛利只对成本已知的同批请求计算（同批用户扣款减成本），并展示覆盖笔数。累计钱包扣款不是现金收入；估算毛利未计服务器费用，不能当作实际利润或供应商余额对账结果。

## 验收

覆盖倍率边界、峰谷/节假日、GPT 人民币参考价、管理员鉴权、同源校验、并发修订冲突、不同模型独立倍率、旧请求与新请求分别结算、成本覆盖和内部测试账号过滤。页面真实组件通过 480 / 1000 像素视口测试：只读弹窗、未保存预览、明确保存、失败保留输入、未知不填零和无横向溢出。

2026-10-15 已部署 Cloud API / Web；线上真实管理员页面验收通过，两张上游卡片与两个未归档模型正确显示，刷新与只读弹窗正常。DeepSeek 余额可读，GPT 余额接口未知。部署前后现有有效费率和倍率设置一致，没有发布新 App。API 单元测试 147 项、独立 PostgreSQL 测试 31 项、Web 单元测试 15 项通过；已覆盖有凭据上游筛选和模型归档隐藏的回归检查。
